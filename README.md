# ru2en — перевод промптов RU→EN для omp

Расширение omp: перехватывает отправляемый текст (событие `input`) и, если в нём есть
кириллица, переводит его на английский до того, как сообщение уйдёт в основную модель.
Перевод выполняется отдельной дешёвой моделью (роль `@smol`).

## Установка через marketplace

```bash
omp plugin marketplace add kreanx/omp-ru2en-plugin
omp plugin install ru-to-en@ru2en
```

Затем нужен **новый запуск** omp (расширения подхватываются при старте сессии).

Удалить: `omp plugin uninstall ru-to-en@ru2en`.

## Модель для перевода

Модель-переводчик выбирается по цепочке (первая доступная):

1. env `RU_TO_EN_MODEL` — любой `provider/model`, авторизованный в omp:

   ```bash
   export RU_TO_EN_MODEL=openai/gpt-4o-mini
   ```

2. роль `@smol` из `modelRoles` в `~/.omp/agent/config.yml` (если настроена);
3. роль `@default`;
4. текущая модель сессии.

Так что отдельная модель не обязательна — без `@smol` перевод пойдёт на модель,
которой вы и так пользуетесь (чуть дороже, один короткий вызов на сообщение
с кириллицей). Если ни одна модель не резолвится или перевод падает — сообщение
отправляется как есть, ввод никогда не блокируется.

## Использование

- Работает в интерактивном и RPC-режиме; `omp -p` (print) хук не вызывает.
- `/ru2en off` — выключить в текущей сессии, `/ru2en on` — включить, `/ru2en status` — статус.
- Сообщения без кириллицы, а также `/команды`, `!bash` и `$python` не трогаются.
- Внимание: в истории сессии остаётся английский текст (оригинал не сохраняется).

## Установка без marketplace (просто файлом)

```bash
mkdir -p ~/.omp/agent/extensions
curl -fsSL -o ~/.omp/agent/extensions/ru-to-en.ts \
  https://raw.githubusercontent.com/kreanx/omp-ru2en-plugin/master/plugins/ru-to-en/translate.ts
```

Перезапустить omp. Выключить: `/ru2en off` в сессии или удалить файл.
