# ru2en — перевод промптов RU→EN для omp

Расширение omp: перехватывает отправляемый текст (событие `input`) и, если в нём есть
кириллица, переводит его на английский до того, как сообщение уйдёт в основную модель.
Перевод выполняется отдельной дешёвой моделью (роль `@smol`).

## Установка через marketplace

```bash
omp plugin marketplace add <repo-url>        # напр. https://github.com/<user>/omp-ru2en-plugin
omp plugin install ru-to-en@ru2en
```

Затем нужен **новый запуск** omp (расширения подхватываются при старте сессии).

Удалить: `omp plugin uninstall ru-to-en@ru2en`.

## Модель для перевода

По умолчанию используется роль `@smol` из `modelRoles` в `~/.omp/agent/config.yml`.
Если роли нет — задайте модель явно через env:

```bash
export RU_TO_EN_MODEL=openai/gpt-4o-mini     # любой provider/model, авторизованный в omp
```

Если модель не резолвится или перевод падает — сообщение отправляется как есть,
ввод никогда не блокируется.

## Использование

- Работает в интерактивном и RPC-режиме; `omp -p` (print) хук не вызывает.
- `/ru2en off` — выключить в текущей сессии, `/ru2en on` — включить, `/ru2en status` — статус.
- Сообщения без кириллицы, а также `/команды`, `!bash` и `$python` не трогаются.
- Внимание: в истории сессии остаётся английский текст (оригинал не сохраняется).

## Установка без marketplace (просто файлом)

Скопировать `plugins/ru-to-en/translate.ts` в `~/.omp/agent/extensions/` и перезапустить omp.
